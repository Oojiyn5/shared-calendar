# 공유 캘린더

카테고리와 메모로 일정을 정리하고, 허용된 사람끼리 여러 기기에서 함께 보는 캘린더 웹앱입니다.
아이폰·안드로이드 홈 화면에 앱처럼 설치할 수 있고(PWA), 인터넷이 없어도 열립니다.

**바로 쓰기:** https://oojiyn5.github.io/shared-calendar/

## 기능

- **월간 달력**: 이전·다음 달 이동, "오늘" 버튼, 날짜를 누르면 그날의 일정 표시
- **일정 추가·삭제**: 제목, 시작·끝 시간(비우면 "하루 종일"), 시간 순 정렬
- **카테고리**: "공부"처럼 나만의 이름과 8가지 색 중 하나로 분류
  - 달력의 점, 일정 왼쪽 막대, 이름표가 카테고리 색으로 표시
  - 카테고리를 지워도 일정은 남고 "카테고리 없음"(회색)이 됨
- **메모**: 일정마다 최대 500자, 줄바꿈 그대로 표시
- **기기끼리 공유(Firebase)**
  - Google 계정으로 로그인
  - 허용 목록에 등록된 계정만 보고 고칠 수 있음
  - 한 기기에서 고치면 다른 기기에 바로 반영
- **오프라인**: 인터넷이 없어도 앱이 열리고 일정을 보고 고칠 수 있음. 다시 연결되면 자동으로 올라감
- **홈 화면 설치(PWA)**: 아이보리 테마, 주소창 없는 전체 화면, 아이폰·안드로이드 아이콘
- **상태 표시**: 화면 위쪽에 `공유 중` / `저장 중…` / `오프라인` / `로그인 필요` / `이 기기에 저장`

## 설치 방법

### 휴대폰 홈 화면에 설치

| 기기 | 방법 |
|---|---|
| 아이폰 | **Safari**로 위 주소 열기 → 아래쪽 공유 버튼(□↑) → **홈 화면에 추가** → 추가 |
| 안드로이드 | **Chrome**으로 위 주소 열기 → 오른쪽 위 ⋮ → **앱 설치**(또는 홈 화면에 추가 → 설치) |
| PC | Chrome·Edge로 위 주소 열기 → 주소창 오른쪽 설치 아이콘 |

홈 화면 아이콘으로 열었을 때 주소창이 없으면 설치된 것입니다.
처음 열면 **Google로 로그인**을 누르고, 허용 목록에 등록된 계정을 고릅니다.

### 함께 쓸 사람 추가

Firebase 콘솔 → Firestore Database → 데이터 → `members` 컬렉션 → **문서 추가**
→ 문서 ID에 그 사람의 Gmail 주소(소문자)를 넣고 필드 하나(예: `name`)를 넣어 저장합니다.
빼려면 그 문서를 지웁니다.

### 직접 만들어 쓰기 (내 Firebase로)

1. 이 저장소를 내려받습니다.
2. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
   - **Authentication**: Google 로그인 사용 설정, 승인된 도메인에 내 사이트 주소 추가
   - **Firestore Database**: 프로덕션 모드로 만들고, **규칙** 탭에 [`firestore.rules`](firestore.rules) 내용을 붙여 넣어 게시
   - **데이터** 탭: `members` 컬렉션에 내 Gmail 주소를 문서 ID로 추가
   - **프로젝트 설정 → 내 앱 → 웹(`</>`)**: 앱을 등록하고 `firebaseConfig` 값을 복사
3. [`firebase-config.js`](firebase-config.js)의 `firebaseConfig`를 내 값으로 바꿉니다.
   `null`로 두면 Firebase 없이 그 기기에만 저장합니다.
4. GitHub Pages(`main` 브랜치 루트) 같은 HTTPS 주소에 올립니다.
   경로가 모두 상대 경로라 하위 폴더에 올려도 동작합니다.

### PC에서 띄워 보기

```
python server.py
```

`http://localhost:8000`으로 엽니다. Python 기본 기능만 쓰므로 따로 설치할 것은 없습니다.
서비스 워커와 Google 로그인은 HTTPS 주소나 `localhost`에서만 동작합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조, PWA·아이폰 meta 태그, 서비스 워커 등록 |
| `app.js` | 달력 그리기, 일정·카테고리, Firebase 로그인·저장, 예전 일정 옮기기 |
| `style.css` | 디자인(아이보리 테마, 휴대폰 화면 대응) |
| `firebase-config.js` | Firebase 설정값 (공개되어도 됨) |
| `firestore.rules` | 누가 읽고 쓸 수 있는지 정하는 보안 규칙 |
| `service-worker.js` | 모든 파일을 미리 저장해 오프라인에서도 열리게 함 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 테마색 |
| `icons/` | 192px, 512px, 아이폰용 180px, 파비콘 |
| `server.py` | PC에서 화면을 띄워 보는 서버 |
